# 小院清理队

微信小游戏原生 JavaScript 起步项目，不依赖 Cocos Creator 或额外 npm 包。

## 当前阶段

- 竖屏 Canvas 初始化和屏幕尺寸适配
- 绘本风田野背景主菜单与触屏切换
- 首页角色选择：四个角色，至尊奶环绕棍近战、瘦嘟嘟自动追踪枪、奶大侠穿透刀光、奶小仙掷伞压制
- **奶大侠 · 月牙刀光**：向最近敌人打出一道横向月牙刀光（攻击间隔 0.88 秒，比瘦嘟嘟的 0.60 秒更慢，但单发倍率 3.4 高于瘦嘟嘟的 1.8）。**刀光命中敌人后不消失**，而是继续沿原方向推进（135 像素/秒），首个受害者吃满伤害，之后的敌人只吃 50%，刀光存在满 2 秒后降为 25%，满 4 秒后缓缓淡出。同一时间可以打出多道刀光，各自独立结算衰减
- **奶大侠 · 无极闪**（主动技能，CD 15 秒）：以自身为中心向 360° 无死角打出一圈刀光，对场上所有可见敌人造成**当前攻击力 500%** 的伤害，附带 16 道刀光射线、冲击波、闪屏与震屏
- **奶小仙 · 掷伞**：向最近的敌人投出旋转的伞，飞向目标途中对**路径上所有敌人造成 100% 伤害**；落到主要目标身上后持续旋转，**每秒造成 50% 伤害，直到该目标死亡或满 8 秒被强制收回**，之后飞回手中（返程同样对路径造成 100% 伤害）。注意：**伞离手期间奶小仙没有任何攻击手段**
- **奶小仙 · 旋转递增**：锁定满 3 秒后，伞的每秒伤害开始按 **1.3 倍复利**递增；第 8 秒时伞被强制收回。实测每秒伤害为 126 → 126 → 126 → 159 → 210 → 268 → 343 → 451（合计约为固定 50% 方案的 4.5 倍），让「磨一只大怪」从亏本变成划算
- **奶小仙 · 归鞘回血**：伞回到手中的瞬间，按**本次投掷对主要目标造成的伤害的 50%** 回复生命（飘出绿色治疗数字）。金色技能「归鞘回春」可把这个比例再翻倍。⚠️ 拿到红色技能「万伞归一」后伞不再回手，这个结算改到**每次换目标的瞬间**触发（见该条目），否则会静默失效
- **奶小仙 · 伞的绘制**：武器伞用素材 `xiaoxian-umbrella.png` 绘制（正圆，与命中判定一致）。**收在身上（`state === 'held'`）的伞不绘制** —— 她的立绘 `xiaoxian-fairy.png` 里本来就画着一把撑在手上的伞，再按 state 画一把就是两把重叠；手上剩几把由 HUD 文案（"伞在手中"）与飞在场上的伞数表达
- **奶小仙 · 伞·引**（金色技能）：伞离手时成为引力中心，把周围 240 像素内的怪拉向自己。牵引强度沿用击退公式 `击退值 / (击退值 + 重量)`，所以**比自身击退值轻的怪会被强力吸过去**（实测 1 秒拉近 128 像素），更重的怪也会被明显牵引（37 像素）。首领与已被眩晕的怪免疫
- **奶小仙 · 反刺玉衣**：伞不在手中时自动生效——受到的所有伤害**减免 50%**、**移动速度 +100%**，并把**受到伤害的 150% 反弹给造成伤害的那只怪**；伞回到手中时玉衣失效。这是她「无攻击」的代价换来的补偿
- **奶小仙 · 伞回**（主动技能，CD 12 秒）：立刻收回伞，并向自身周围甩出 **12 把伞**再立即收回，每把伞造成**普通攻击 120%** 的伤害
- **奶大侠 · 破军斩**：除攻击力 +8、刀光伤害 +8 外，**每次出刀有 50% 概率触发双连击**——追加一道完整的月牙刀光（同样吃满暴击、金红倍率等全部加成），最多可叠到 100%
- **奶大侠 · 无极剑阵 / 寂**（攻击形态进阶）：一次普通攻击的刀光数达到 **6** 时转为「**无极剑阵**」——全部刀光不再并排指向目标，而是**以 360° 等分全方位向外打出**；达到 **12** 时全部刀光**合成一道环形超级刀光「寂」**，由内向外扩张（伤害 = 单道刀光伤害 × 刀光数，所以"合成"不损失总伤害，但能同时覆盖四面八方）。合成「寂」之后，任何「多刀光」的技能都不再加刀光，改为按"本该加几道"折算成**「寂」的伤害（每道 +20%）** —— 「双锋」+40%、「三刀流」+60%、「剑阵引导」+80%。三张加刀光的卡：**双锋**（紫）+2 道、**三刀流**（金）+3 道且**攻速 +50%**、**剑阵引导**（金）+4 道。联动：**宽刃 / 横扫千军** 提升的横向范围会直接变厚「寂」的环带，**破空劲 / 刀锋所指** 提升的推进速度会加快「寂」的扩张，**刀气纵横 / 余劲不散** 让「寂」不衰减，**血月斩** 让「寂」扫过的每一处都炸出小血月。注意**长夜刀的折返只作用于方向性刀光，「寂」不折返**。另外**进入无极剑阵 / 寂之后，所有刀光的厚度再降为 30%**（`daxiaWaveFormBladeScale`）—— 刀锋的径向厚度是「内弧半径差 `half×0.07`」与「内弧后移量 `thick×1.9`」**两项之和**，所以两项一起缩才得到 30%（只缩后移量会停在 48%）；**命中判定一行不动**
- **奶大侠 · 血月斩**（红色专属）：攻击力 +12、刀光伤害 +12、刀光横向 +50；**刀光每命中一个敌人，都会在该处炸出一道小型血月**（威力为当前刀光的 70%，横向范围 45%，且不会再继续扩散）。密集怪群里刀光会像滚雪球一样炸开一片。**小血月是深红色**（主刀光是冰蓝），同屏时一眼能分出"自己打的"和"炸出来的"；小血月命中时的飘字与粒子同样是红色
- **奶小仙 · 万伞归一**（红色专属）：伞未回手时也能继续投掷，**场上最多同时存在 3 把伞**；第一把伤害不变，之后依次为 **50% / 25%**，且**不会锁定同一目标**（飞行中的伞也会预定目标）。**伞不再被回收** —— 杀掉当前目标后会自动寻找场上**绝对血量最高**的敌人继续攻击（判据是绝对生命值，不是百分比也不是距离，因为伞的价值在于磨厚血目标）；不再固定 8 秒收伞，而**伤害递增封顶在原来 8 秒时的倍率**（`spinTime` 封顶在 `umbrellaMaxSpin`，最大仍是 `1.3^5 ≈ 4.8` 倍），所以这条改动只是"取消收回"、没有顺带放大伤害。**「归鞘回血」的触发点从"回手瞬间"改到"换目标瞬间"** —— 否则伞永不回手会让这个机制静默失效。作为代价，**反刺玉衣转为永久生效**，但减伤降为当前的 30%（50% 减伤 → 15%）、反伤降为当前的 75%（150% → 112.5%）
- **奶小仙 · 伞舞**（常驻操作）：**点击场上任意一把伞即可让它提前飞回**，返程同样对路径造成 100% 伤害。这是她在「伞离手、无法攻击」期间的主动决策——把伞留在场上继续磨，还是提前收回换一次穿透。HUD 会提示「点击伞可提前收回」
- **奶小仙 · 伞阵**（金色技能）：**自身与每把伞之间、以及伞与伞之间形成伤害帘幕**，敌人穿过时持续受伤。只有一把伞时它就是一条「伞线」，拿到万伞归一后会变成一张网——这把「伞越多越强」从数量叠加升级成了空间玩法
- **奶大侠 · 索敌（一人一刀）**：一次普通攻击里的**每道刀光各索一个不同的敌人**（按最近的优先认领），不会再出现"三道刀光追着同一个小怪打、其余敌人没人管"的情况。刀光数超过敌人数时才轮流分配，同一个目标分到多道刀光时会**横向错开并居中**，避免完全重叠。**无极剑阵**（固定 360° 等分）与**寂**（一道环）不吃这套分配，但仍用最近敌人的方向作为主轴

- **奶大侠 · 残心**（长夜刀进化）：**刀光抵达尽头后原路折返**，把同一条路线再割一遍，且返程按**满伤害**重新结算（重置存在时间、命中表与**命中锚点**，不是残血版的回程）
- **升级卡片的简要 / 详细描述**：卡片默认只显示**简要描述**（取首个分句），说明较长的技能会在简要文字右侧出现一个 **「详细 ›」** 按钮，点开后进入**独立的详情页**显示完整长文本、稀有度与该项对怪物的强化说明，底部「返回」回到选择界面
- **瘦嘟嘟 · 子弹分配目标**：全队子弹原本各自挑选"血量最低的敌人"，导致一轮齐射全部堆在同一只怪身上，而怪海其余部分无人处理。现在改为**按顺序认领目标**——同一轮里每颗子弹优先锁定**还没有被其他子弹认领**的敌人，只有所有可达敌人都被认领后才会重复锁定。索敌机制因此从"集火"变成"铺开"- **瘦嘟嘟 · 弹药体系**（重做，三个金色技能互相咬合、红技能是出口而不是孤立技能）
  - **赤焰弹幕（红）**：不再写死。**每次发射都重新读取当前枪械数据**——子弹数 = 4 + 弹数 + 每项弹药机制 ×2；伤害 / 暴击率 / 暴击倍率 / 穿透数 / **冲击爆破**全部继承主武器；**发射间隔随射速缩短**（射速拉满时从 2.2 秒降到 0.55 秒）；**子弹速度随弹速提升**
  - **精准连射（金）**：子弹伤害 +8、弹数 +1、射速 −0.12；机制「**弹链**」——每 3 轮射击追加一次 6 发环形齐射；**若已解锁赤焰弹幕，该齐射会为弹幕返还 0.25 秒冷却**（两个技能互相供能）
  - **重炮弹头（金）**：击退 +7、子弹伤害 +6；机制「**冲击爆破**」——**子弹每次命中**（不只是最后一次）都炸开半径 62 的爆破，造成 40% 伤害并击退；**赤焰弹幕的子弹同样会爆破**，所以穿透弹在怪群里会拖出一串爆炸
  - **穿甲暴击弹（金）**：暴击率 +10%、暴击倍率 +0.5；机制「**穿甲**」——**暴击的子弹额外穿透 +2**，赤焰弹幕全额继承穿透数

- **瘦嘟嘟 · 弹幕圈**：赤焰弹幕不再是一撮零散的子弹，而是**一圈均匀铺满 360° 的环**。每次拿到「增加弹幕子弹」的技能，环就补厚一层，到 **14 发时弧线首尾相连，形成环绕瘦嘟嘟的完整弹幕圈**（HUD 有独立的成型进度条）。关键改动：
  - 子弹永远以 `2π/发数` 等分圆周，实测无论 5 发还是 26 发，相邻间隔误差为 0，整圈严丝合缝
  - 每发子弹画一段**以自身方位为中心的圆弧**，弧长随成型度从 22% 长到 100% —— 所以成型过程是"看得见"的，从断续的点变成连成一片的环
  - 弹数封顶（8）后，原本「双发点射 / 精准连射」会变成死牌（只加伤害）；现在这两项在封顶后会继续给**弹幕圈补子弹**，红色弹幕不会因为弹数满而停止成长
  - 同屏弹幕上限从 14 提到 56（两圈完整弹幕），否则一轮齐射会被截断成"缺角的半圈"；同时寿命 1.1→0.95 秒，密集的环仍然是一道扫出去的波而不是糊屏
  - 实测成长曲线（**2025 全部技能数值 ×1.3 后的新曲线**）：刚拿到赤焰弹幕 **7 发** → +双发点射 **9 发** → 再 +双发点射 **12 发** → +精准连射 **17 发(已 100% 成型)** → +重炮弹头 **20 发** → +穿甲暴击弹 **22 发**（上限 26）。公式已改为 `5.2 + 弹数×1.3 + 每项弹药机制×2.6`，"成型"判定线仍是 `radialRingFull = 14` 发，所以现在**成型得更早**。旧曲线是 5 → 6 → 7 → 10 → 12 → 14 发
- **瘦嘟嘟 · 手雷索敌**：只在**屏幕内**的敌人中选目标（越界 24 像素才算离屏），不会再把雷丢到屏幕外
- **瘦嘟嘟 · 反哺**（新的金色技能）：**每次击杀永久 +0.5% 最终伤害**（上限 **+200%**），并**回复 1 点生命**。两个关键性质：① 每杀的增量**与等级无关**（升到多少级都是 0.5%/杀，不随成长曲线放大）；② 它是**独立乘区、算在所有加成的最后** —— 在 `applyAttackDamage` 里写成 `基础伤害 × 暴击 × 连杀 × (1 + 反哺)`，乘的是已经结算完的伤害，所以不会被暴击或连杀重复放大。参数在 `balance`：`rabbitFeedPerKill / rabbitFeedCap / rabbitFeedHealPerKill`；解锁标记是 `game.rabbitFeed`，累积值 `game.rabbitFeedBonus`
- **瘦嘟嘟 · 全部技能数值 ×1.3**（按需求统一上调）：连续型数值（伤害 / 速度 / 生命 / 百分比 / 击退 / 半径 / 冷却缩减）一律 ×1.3，保留小数。**计数型**（穿透、弹数、暴击穿透、弹幕圈）取 `Math.ceil(v×1.3)` —— 分数穿透在代码里等价于 `floor`（每次命中减 1），写 1.3 等于没加强；这与 `scaleCharacterStats()` 里对 `projectileCount / projectilePierce / orbitStickCount` 已有的 `Math.ceil` 是同一套口径。**上限 / 下限 / 频率不乘**：暴击率 0.75、手雷百分比 0.45 / 0.15、射速下限 0.30、手雷冷却 5 秒、弹链"每 3 轮"都保持原值 —— 上限与下限不是"数值的增加"，而改频率是重做卡的身份而不是加强。**四张共享白卡（轻便鞋子 / 奋勇强攻 / 急救包 / 坚韧外衣）也没有乘**：它们四人共用，乘了会连带加强另外三个角色。藏在派生公式里的金/红卡数值（爆破半径 62→80.6、爆破倍率 0.4→0.52、弹链齐射 6→8 发、齐射返还 0.25→0.325 秒、赤焰弹幕弹数公式 `4+弹数+机制×2` → `5.2+弹数×1.3+机制×2.6`）在 `balance` 里一并乘了，原值写在那边注释里

- **技能稀有度阶梯**：此前白色「奋勇强攻」攻击力 +4，同时压过蓝色「强力棍子」+1 与金色「破军扫棍」+3，稀有度越高反而越弱。现在固定攻击力严格按白 +2 / 蓝 +3 / 金 +7~8 / 红 +12 排列，高稀有度额外附带暴击、范围、击退等效果。**注意**：技能「主效果撞上限后转为攻击力」的兜底产出（例如蓝色「快速旋转」的 +1）**刻意不属于**该阶梯，不应误读为倒挂。校验脚本 `tools/verify.mjs` 会从源码解析技能表、断言该阶梯不倒挂，并可随时复跑：`node tools/verify.mjs`（退出码 0 = 全部通过）
- **撞到上限的技能不再作废**：多个技能受数值上限约束（移动速度、暴击率、射速、子弹速度、手雷冷却与范围、弹数、旋转速度、棍击距离），一旦顶到上限，原本后续抽到等于白抽。现在每个都带兜底产出（转为攻击力或子弹伤害等）。追踪芯片原本因新增子弹速度上限只能生效约 2 次，现改为速度 +80 与转向 +1.0，速度满后转子弹伤害 +2
- 瘦嘟嘟子弹配色加深：弹体由近白改为深金色 `#ffb01f` 并加暗色描边与高光点，拖尾改为橙色；弹幕改为深红 `#d92f14`，在浅绿草地上对比度明显提高
- **追踪弹不再凭空消失**：失去目标时改为沿原方向滑行并在 0.3 秒内淡出缩小，同时飞出画面的子弹会被回收；此前是直接删除，观感像子弹突然蒸发
- **割草视觉累积**：击杀位置留下约 6 秒的地面割痕（最多 90 处），打完一片地会有明显被清理过的痕迹；每次击杀有种子粒子飞向 HUD 计数；棍子带 0.055 秒的拖尾残影，雷电棍额外画出电弧连线
- **连杀里程碑**：连杀达到 10 / 25 / 50 / 100 / 200 / 350 / 500 时触发事件——显示「×N 连杀！」，放出冲击波推开周围敌人、闪屏、震动并叠加音调
- **首领处决演出**：首领血量归零后进入 1.5 秒处决段，全场降到 0.3 倍速、首领冻结在 1 血并持续闪白，结束后才结算掉落与胜利
- **武器进化 = 一次大招**：确认进化的瞬间对全场可见敌人造成 3.2 倍攻击力的伤害、清空周围 520 像素、获得 1.2 秒无敌并大幅闪屏震屏
- **怪物潮方向预警**：金/红技能触发怪物潮时，屏幕边缘出现红色箭头指向来袭方向，持续 2.4 秒
- **首领二阶段**：血量降到 50% 时首领狂暴，移速 ×1.35、冲锋间隔由 3.2 秒缩短到 2.2 秒，并召唤 3 名援军
- **难度橡皮筋**：按同屏敌人占上限的比例动态调整刷怪速度（0.75~1.6 倍）。场地太空时加压、长期挤满时减压，让节奏稳定停在高潮区间
- **结算滚动数字与评分**：结算界面数字在 1.1 秒内滚动到最终值，并按击杀数、连杀峰值、等级与是否通关给出 S/A/B/C 评价与称号

## 代码组织

- 全部逻辑位于单文件 `game.js`，无构建步骤、无第三方依赖
- 所有可调数值**原则上**集中在文件顶部的 `balance` 配置表，`startGame()` 只负责按表组装本局状态。
  ⚠️ 实测并非全部：`balance` 的 **203** 个键里有若干当前无人读取，且**怪物基础属性、升级卡数值、稀有度权重、各角色上限**住在表外（D6 第1轮实测；此前此处写 187 为过期值，`tools/verify.mjs` 的 A2.1 会打印真实键数）
- 所有可点击区域由纯函数计算（`menuLayout()`、`backButtonBounds()`、`pauseButtonBounds()` 等），绘制与触摸判定共用同一份坐标，不再依赖「上一次绘制写入的全局变量」（此条已逐界面核对，成立）
- 敌人数量上限由单一入口 `enemyCapacity()` 判定。刷怪入口 `spawnEnemyAtEdge()` 的调用点**故意分成两种口径**：环境刷怪用 `false`（把 `eventEnemyReserve` 让给事件与首领），怪潮 / 精英突袭 / 首领用 `true`。理由见 `spawnEnemy()` 内注释
- **自检脚本**：`node tools/verify.mjs` —— 零依赖，静态读取源码（不加载 `game.js`，因为它顶部就要 `wx.createCanvas()`），退出码 0 表示全部通过。16 条断言覆盖稀有度阶梯与注释一致性、`balance` 重复键、容量口径契约、`enemies.push(` 单一入口、素材双向引用等

## 素材规格

美术资源按下表压缩，`assets/` 合计约 0.8 MB，含代码的整体包体约 0.94 MB（微信小游戏主包上限 4 MB）。

⚠️ **此前这里写「缩放时保持了原始宽高比」—— 那句话只对敌人成立，对 4 个主角不成立**（D6 第1轮实测更正）：敌人贴图宽度由 `sprite.width / sprite.height` 推导，所以比例自洽；但 4 个主角走的是 `drawFacingSprite`（`game.js:2435-2442`），它直接 `drawImage(..., w, h)` **不做任何比例校正**，而 `characterRender`（`game.js:64-69`）是写死的画盒。两边比例不一致时素材就会被拉伸，实测：
**瘦嘟嘟 336×333（1.009）画进 112×126（0.889）→ 水平压缩 11.9%**、蓝棍 −3.3%，至尊奶 / 奶大侠 / 奶小仙 / 首领误差均 <0.5%。换素材时必须按**画盒**比例出图，或同步改 `characterRender`。

| 敌人贴图 | 高 303~336 | 按 `半径 × 3.05` 绘制，像素比 3 |

两张新立绘的原图是纯白背景，直接抠白会把奶小仙的米白长袍一起吃掉，所以背景是用**从图像边缘向内的连通域填充**移除的（只清除真正与外部相连的白色区域），再把蒙版外扩 1 像素吃掉抗锯齿残留的白边。

`xiaoxian-umbrella.png` 用的是同一套方法，而且**这个坑在这里更险**：原图是 1779×1734 的纯白底 RGB（无 alpha），但伞面纸色是 `(226,242,242)` —— **离纯白只有 29**。所以任何"接近白就透明"的颜色阈值都会把浅色伞面一起吃掉。做法是从八个边缘种子（四角 + 四边中点）做 flood fill（容差 16），再外扩 2 像素吃掉白边，最后**居中方形裁切**（内容实测占图宽 91.2%，裁掉留白后不透明内容正好填满 512×512，于是代码里"伞半径 = R"可以直接映射成"贴图边长 = 2R"，不需要魔术常数）。

⚠️ 伞**画成正圆**，不沿用旧的 0.55 压扁椭圆 —— 因为**命中判定本来就是正圆**（`updateOneUmbrella` 用 `distanceBetween(enemy, umbrella) > umbrellaRadius + enemy.radius`），旧画法等于一直少画了近一半的判定范围。素材没加载出来时兜底仍画旧的椭圆代码伞，所以**删掉这张图就完整回退到旧表现**。
