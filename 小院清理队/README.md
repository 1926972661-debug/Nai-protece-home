# 小院清理队

微信小游戏原生 JavaScript 起步项目，不依赖 Cocos Creator 或额外 npm 包。

## 当前阶段

- 竖屏 Canvas 初始化和屏幕尺寸适配
- 绘本风田野背景主菜单与触屏切换
- 首页角色选择：至尊奶使用环绕棍攻击，瘦嘟嘟使用自动追踪枪弹
- 瘦嘟嘟使用独立升级池，包含弹头强化、快速装填、多发、穿透与追踪等枪械技能
- 枪弹自动锁定附近敌人、飞行追踪并有碰撞伤害；至尊奶保留棍子环绕攻击
- 两位角色均可使用各自朝向镜像、自动战斗、冲刺和小院成长加成
- 屏幕任意位置触控移动、自动攻击和追踪敌人
- 4 屏宽高地图、人物跟随镜头与固定地标
- 黄色主角与旋转棍子环绕攻击，初始 1 根
- 基础敌人使用黄色怪物素材；猿怪、夜行客、壮壮怪、疾跑怪和精英怪各自使用独立角色素材，并根据水平移动方向镜像
- 棍子数量升级可重复选择，不设数量上限
- 棍子按长条碰撞体命中，每次造成 2 点基础伤害；小怪生命值为 10
- 每次升级自动增加 1 点基础攻击力，攻击强化选项在此基础上额外增加
- 经验拾取、三选一升级与可叠加技能
- 5 波递增敌人、限时首领登场与冲锋攻击
- 新增丛林猿、夜行客敌人素材，按横向移动方向镜像；敌人图鉴记录遭遇和击败次数
- 每 30 秒推进一波并记录击杀目标，完成波次挑战可获得额外种子
- 局内随机事件：守护花圃、限时采集、精英怪突袭；目标位置同步显示在小地图
- 瘦嘟嘟可通过枪械组合进化为散射弹、爆裂弹或连锁弹；至尊奶可进化雷电棍
- 战斗中可点击左上角“结算”提前结束本局，按当前击杀和已收集奖励结算
- 首领使用王座皇冠角色素材，并按水平移动方向镜像；垂直移动保持最近朝向
- 主动冲刺、冷却反馈与冲撞伤害；棍子数量和冲刺强化可联动增伤
- 角色朝向约定：只在水平移动时更新朝向，上下移动保留上次方向；绘制统一使用 `drawFacingSprite`
- 小院 8 种装饰可各升至 10 级，装饰在战斗地图出生区域同步显示，并提供对应属性加成
- 地图随机出现 12 种蓝/紫/金稀有植物；每种植物首次收集会永久强化角色，重复植物转为种子
- 植物图鉴展示 3 件蓝色、4 件紫色、5 件金色收藏和三套集齐加成
- 小地图定位角色与植物掉落；稀有植物以稀有度颜色脉冲高亮
- 击败首领有 30% 概率掉落红色隐藏植物，限时拾取后加入图鉴并获得隐藏加成
- 胜利/失败结算和重新开始
- 角色步行动画、命中粒子、受击反馈和基础音效
- 本地保存金币、最佳生存时间、击杀纪录及已解锁/装备外观
- 小怪经验掉落改为粽子图标；拾取同时获得种子，击退首领额外奖励种子
- 粽子掉落素材已处理透明背景并放大显示，带有金色拾取光圈
- 小院装饰等级、种子、植物图鉴和植物永久加成通过微信本地存档保存
- 冲刺按钮位于战斗画面右下角，冲刺方向跟随当前移动方向；静止时按角色朝向冲刺

## 导入运行

使用微信开发者工具导入本目录。项目当前使用游客 AppID；正式预览、真机调试和发布时，请在 `project.config.json` 中填写自己的小游戏 AppID。

后续阶段可补充更多美术动画、音效和本地解锁进度。
